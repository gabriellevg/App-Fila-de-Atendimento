# Sistema de Fila de Atendimento

Sistema web para gerenciamento de fila de atendimento desenvolvido com:

- Python
- Flask
- SQLite
- HTML
- CSS

## Funcionalidades

- Cadastro de clientes
- Visualização da fila
- Atendimento por ordem de chegada (FIFO)
- Alteração de status
- Status aguardando
- Status em atendimento
- Status concluído
- Cancelamento de atendimento
- Dashboard com quantidade de clientes por status
